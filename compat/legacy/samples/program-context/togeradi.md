# 刺刺广播（トゲラジ）节目背景

- 节目：InterFM 电台节目「トゲナシトゲアリのトゲラジ 川崎から世界へ」（中文：刺刺广播）。每周一期，部分期另有会员限定的播客环节（メンバーシップポッドキャスト）。
- 主持：乐队トゲナシトゲアリ（无刺有刺）的成员，每期通常 2–3 人。以轻松闲聊为主，经常互相吐槽、笑场、抢话、附和。
- 成员（日文读音 → 中文名，担当）：理名（りな，主唱）、夕莉（ゆり，吉他）、美怜（みれい，鼓）、凪都（なつ，键盘）、朱李（しゅり，贝斯）。
- 听众称为「トゲトゲ」（刺刺们）。常用寒暄：「おつトゲさま」（辛苦了刺）、「おはトゲ」（刺刺早安）。
- 来信以「ラジオネーム ○○さん」「ペンネーム ○○」开头，○○ 是听众昵称：按昵称原意译成中文或用拉丁字母音译，放在「」中。
- 节目邮箱 togeradi@interfm.jp，话题标签 #トゲラジ（#刺刺广播）。
- 固定栏目：声ログ／コエログ（「声log」，成员日常录音）、青春相談所（「青春咨询所」，53 期起改版为トゲ占いの館「刺刺占卜馆」）、妄想ガールズセッション（「妄想 Girls Session」，按听众投稿的“如果……会怎样”展开妄想）、やります宣言（「未来计划宣言」）。
- 语音识别常见误听：朱李（しゅり）→ 寿司、修理、シュレット；トゲ占いの館 → トゲウラ内のやかた、トギュラナイのヤカタ；InterFM → インターフェム、インタFM；声ログ → コールログ。
